# Skirt Physics

A [Dusklight](https://github.com/TwilitRealm/dusklight) mod by ByTheEightDivines. Adds hat-style momentum and wind
physics to anything weighted to Link's outer skirt bones (joints 27-34). Panels only swing outward, never inward.

Built from the official [mod-template](https://github.com/TwilitRealm/mod-template). Tuning values are at the top of
`src/mod.cpp`.

## Download

Push a tag (e.g. `v1.0.7`) and the GitHub Actions workflow publishes a release containing the single cross-platform
`skirt_physics.dusk`. Copy it into your mods folder:

- Windows: `%APPDATA%\TwilitRealm\Dusklight\mods`
- Linux: `~/.local/share/TwilitRealm/Dusklight/mods`
- macOS: `~/Library/Application Support/TwilitRealm/Dusklight/mods`
